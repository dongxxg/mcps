## ADDED Requirements

### Requirement: 保质期字符串解析
系统 SHALL 解析带单位的保质期字符串，提取数值和单位。支持的格式：`"180天"` / `"12个月"` / `"2年"` / `"180"`（纯数字默认=天），单位关键词：天/日、月/个月、年。

#### Scenario: 解析"X天"格式
- **WHEN** 保质期列值为 "180天"
- **THEN** 解析为 数值=180，单位=天

#### Scenario: 解析"X个月"格式
- **WHEN** 保质期列值为 "12个月"
- **THEN** 解析为 数值=12，单位=月

#### Scenario: 解析"X年"格式
- **WHEN** 保质期列值为 "2年"
- **THEN** 解析为 数值=2，单位=年

#### Scenario: 纯数字（默认天）
- **WHEN** 保质期列值为 "180"（无单位）
- **THEN** 解析为 数值=180，单位=天

#### Scenario: 无法解析的格式
- **WHEN** 保质期列值为 "半年" 或 "abc" 等无法解析的字符串
- **THEN** 系统抛出 `TransformError`，消息包含原始值和列名

### Requirement: 过期日期计算
系统 SHALL 根据生产日期和解析后的保质期（数值+单位），计算每行产品的过期日期。

#### Scenario: 单位为天
- **WHEN** 生产日期 2026-01-01，保质期 "180天"
- **THEN** 过期日期为 2026-06-29

#### Scenario: 单位为月
- **WHEN** 生产日期 2026-01-15，保质期 "6个月"
- **THEN** 过期日期为 2026-07-15

#### Scenario: 单位为年
- **WHEN** 生产日期 2024-06-01，保质期 "2年"
- **THEN** 过期日期为 2026-06-01

### Requirement: 保质期分数阈值判断
系统 SHALL 支持配置阈值分数 `fraction`（如 1/3、1/2），判断参考日期是否已超过该分数的保质期。

#### Scenario: 判断是否过 1/3 保质期
- **WHEN** 生产日期 2026-01-01，保质期 "365天"，fraction=1/3，参考日期 2026-03-01
- **THEN** 1/3 阈值日期约 2026-05-01，参考日期未超过 → 输出 False

#### Scenario: 判断是否过 1/2 保质期
- **WHEN** 生产日期 2026-01-01，保质期 "365天"，fraction=1/2，参考日期 2026-08-01
- **THEN** 1/2 阈值日期约 2026-07-01，参考日期已超过 → 输出 True

#### Scenario: 自定义分数（如 2/3）
- **WHEN** fraction=2/3
- **THEN** 按 2/3 保质期计算阈值日期并判断

### Requirement: 参考日期可配置
系统 SHALL 支持传入 `reference_date`（默认为系统当前日期），用于测试和回溯。

#### Scenario: 指定参考日期
- **WHEN** reference_date=2026-12-31，生产日期 2026-01-01，保质期 "180天"
- **THEN** 按 2026-12-31 判断，显然已过期 → 输出 True

#### Scenario: 默认使用系统当前日期
- **WHEN** 未传 reference_date
- **THEN** 使用 `date.today()` 作为参考日期

### Requirement: 输出列可配置
系统 SHALL 允许用户指定输出列名，输出为布尔列（是否超过阈值）。

#### Scenario: 自定义输出列名
- **WHEN** output_col="是否过1/3保"
- **THEN** 新增列 "是否过1/3保"，值为 True/False

### Requirement: 空值处理
系统 SHALL 对生产日期或保质期为 None / 空字符串的行有明确定义的处理。

#### Scenario: 生产日期为空
- **WHEN** 某行生产日期为 None
- **THEN** 该行输出列值为 None，不抛错

#### Scenario: 保质期为空字符串
- **WHEN** 某行保质期为 ""
- **THEN** 该行输出列值为 None，不抛错
